## Lessons Learned & Gotchas
- Standard build: `npx electron-builder --mac dir --arm64 -c.appId=com.lucasyoung.neo-mcp -c.productName="NEO MCP" -c.mac.identity=- -c.mac.notarize=false`. The packed package.json keeps `productName: NEO`, so userData stays `~/Library/Application Support/NEO` (settings `mcp.enabled`, `mcp.port` 47811; token in `secrets.json`). Do not change package.json `productName`.
- Verify an install with the same path Claude Code uses: spawn the `neo` server from `~/.claude.json` (`/opt/homebrew/bin/node .../scripts/mcp-stdio.js`, env `NEO_MCP_TOKEN`), send initialize, tools/list, `list_books`. Never print the token.
- After the app starts, the MCP port takes about 8 to 11 s to listen.
- Upstream does not set Electron fuses; Playwright's `_electron.launch` relies on the `--inspect` / remote-debugging path those fuses leave open.
- Pipe e2e output through `grep -vE '^ok '` rather than `tail -1` so failing case names are kept.
